# All Green Foundation Website

A responsive static website for a community garden and environmental education
foundation in Mitchells Plain, Western Cape.

## Pages
Home, About, Our Garden, Activities, Gallery, Produce, Events, Enquiry,
Contact, Sitemap, and 404 page.

## Part 3 functionality
- HTML5 and JavaScript form validation.
- Enquiry form provides a response based on the selected topic.
- Contact form prepares an email using the visitor's email application.
- Numbered garden photographs open in an accessible lightbox.
- Event cards can be filtered using search.
- Responsive styling and reduced-motion support.
- SEO metadata, robots.txt, and sitemap.xml.

## Forms
The enquiry form is a front-end demo; it does not send or store form data.
The contact form uses mailto and depends on the visitor's email application.
Connect a secure backend or form service before collecting real submissions.

## Run locally
Open index.html in a browser or serve the project folder with a local static
web server. Preserve the images/ and js/ directories.

## Deployment
Deploy the project as a static site with GitHub Pages or Netlify. Replace
placeholder domains in robots.txt and sitemap.xml with the published domain.
